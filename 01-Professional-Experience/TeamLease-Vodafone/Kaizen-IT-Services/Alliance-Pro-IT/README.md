## 4. Practical IT Administration Workflows

1. Receive an approved employee onboarding request.
2. Create the Microsoft 365 user account.
3. Assign the required license.
4. Configure the necessary account settings and access.
5. Verify the account and license assignment.
6. Update the onboarding records.

### Endpoint Management Workflow

1. Identify and verify the endpoint device.
2. Check the Endpoint Central agent status.
3. Review device inventory and health information.
4. Check missing patches and software requirements.
5. Deploy approved updates or software.
6. Verify deployment status.
7. Update the relevant IT records.

2. Review configured alerts and collected events.

4. Analyze unusual activity or high-volume events.
5. Review storage consumption and trends.
6. Document findings and coordinate further investigation when required.
